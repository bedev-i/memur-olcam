# Memur Olcam

Kamu iş ilanlarını tek yerde toplayan **ücretsiz** Windows uygulaması.

- Kariyer Kapısı, kamuilan.sbb.gov.tr, Resmî Gazete, İŞKUR ve ÖSYM ilanları
- Alan, il, eğitim düzeyi, kadro türü ve KPSS puan türüne göre filtre
- Yeni ilan / son gün bildirimleri, ilan takibi
- "Başvur" ile başvuru formunu otomatik doldurma (formu sen gönderirsin)

## İndir
[**Releases**](../../releases/latest) sayfasından `MemurOlcam.exe` dosyasını indir ve çalıştır (kurulum gerekmez).

> İlk açılışta Windows "Bilgisayarınız korundu" uyarısı verebilir: **Ek bilgi → Yine de çalıştır**.
> (Uygulama henüz imzalı değil.)

Bu uygulama resmi değildir; hiçbir kamu kurumuyla bağlantısı yoktur. Kişisel bilgiler sadece kendi
bilgisayarında şifreli saklanır.
